# PasteMax

PasteMax is a modern file viewer application for developers to easily navigate, search, and copy code from repositories.

## Features

- Navigate through files and folders with ease
- Search for specific content within files
- Copy code snippets with a single click
- Sort files by various criteria (date, size, type, token count)
- Paste content directly to text areas

## How to Run

1. Install dependencies:
   ```
   npm install
   ```

2. Build the application:
   ```
   node ./node_modules/vite/bin/vite.js build
   ```

3. Start the application:
   ```
   npm start
   ```

## Troubleshooting

If you encounter a blank screen or other issues:

1. Make sure all dependencies are installed properly
2. Rebuild the application using the command above
3. Check the developer console for any errors (open DevTools in Electron)

## Development

To run in development mode:
```
npm run dev
```

This will build the application and start it with Electron.
